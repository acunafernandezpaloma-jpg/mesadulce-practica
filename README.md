## Funcionamiento de JavaScript

Se utilizó JavaScript para desarrollar un menú interactivo de compra de cookies para Mesa Dulce. El programa permite seleccionar un sabor, consultar su precio, ingresar una cantidad y verificar la disponibilidad de stock.

Se implementaron tres funciones principales:

- **`hayStock()`:** verifica la disponibilidad de unidades.
- **`calcularTotal()`:** calcula el importe de la compra.
- **`mostrarTotal()`:** muestra el total y lo registra en la consola.

Además, se incorporaron estructuras condicionales (`if/else`), `switch`, ciclos `while` y métodos de interacción (`prompt`, `alert` y `confirm`). Al confirmar el pago, el sistema actualiza automáticamente el stock disponible.
