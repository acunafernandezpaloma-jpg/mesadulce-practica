Mesa Dulce, cafetería de confianza

Mesa Dulce es un sitio dedicado a la pastelería y a la presentación de propuestas dulces para distintas ocasiones. Aquí se pueden conocer nuestros productos, consultar información sobre los cursos y explorar una galería de creaciones. Buscamos ofrecer una experiencia clara y agradable para quienes desean encontrar inspiración o conocer más sobre nuestro trabajo.

Tecnologias utilizadas:
- HTML5: Maquetación semántica y optimización SEO básica.
- CSS - SCSS: Diseño responsive, animaciones y arquitectura modular.
- Git & Github: Control de versiones y hosting a través de GitHub Pages.

Secciones del sitio:
- Inicio
- Galeria
- Cursos
- Nosotros
- Preguntas frecuentes
- Contacto
